# واجهات إدارة التشغيل والمسارات والامتثال

أضيفت هذه الواجهات لربط لوحة Next.js مباشرة بواجهات API الخاصة بالحسابات، والمسارات الديناميكية، وأهلية الأسطول، ورفع الصور والوثائق.

## الصفحات

- `/admin` — اختصارات مباشرة للمسارات والأسطول والامتثال والحسابات.
- `/admin/users` — إنشاء المستخدمين والموظفين، تعديل الأدوار، تعليق وتفعيل الحساب، وإعادة تعيين كلمة المرور.
- `/admin/drivers` — إنشاء السائق مع مركبته الأولى، مركز التشغيل، وصلاحيات الدول.
- `/admin/drivers/{userId}` — إدارة ملف السائق والمركبات والصور والوثائق والتصاريح.
- `/admin/routes` — إدارة مناطق التشغيل والمواقع والمسارات الديناميكية.
- `/admin/pricing` — تسعير كل مسار حسب نوع الحجز.
- `/admin/compliance` — متطلبات وثائق الدول، تقرير الانتهاء، ومراجعة الملفات المرفوعة.
- `/admin/bookings` — تحميل السائقين والمركبات المؤهلين ثم تعيينهما للحجز.
- `/admin/runs` — إنشاء رحلة تشغيلية لمسار ديناميكي واختيار سائق ومركبة مؤهلين.

## التسلسل التشغيلي المقترح

1. أنشئ مركز التشغيل أو الدولة من `/admin/routes` عند الحاجة.
2. أنشئ المواقع، ثم أنشئ المسار وحدد الدول المطلوبة له.
3. أضف السعر من `/admin/pricing` حتى يصبح المسار قابلًا للحجز.
4. أنشئ السائق والمركبة من `/admin/drivers` وحدد مركز وصلاحيات كل منهما.
5. افتح ملف السائق وارفع الصور والوثائق واعتمدها.
6. عرّف متطلبات الدولة من `/admin/compliance`.
7. أنشئ حجزًا، ثم استخدم «تحميل المؤهلين» لتعيين السائق والمركبة.

## الصور والوثائق

- صورة السائق وصور المركبة ترفع من صفحة ملف السائق.
- يجب اعتماد الملف قبل ربطه بالصورة العامة.
- وثائق الرخص والتصاريح ترفع كملفات خاصة ولا تظهر للمسافر.
- يظهر للمسافر ملف السائق العام وصورة المركبة المختارة بعد التعيين، ويظهر الهاتف بعد قبول السائق للمهمة.

## المسارات الديناميكية

نموذج الحجز العام يجلب المسارات من `GET /api/routes`، لذلك أي مسار فعال وله سعر فعال يظهر تلقائيًا، دون تعديل الواجهة أو إضافة قيمة enum جديدة.
