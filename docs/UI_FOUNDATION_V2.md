# UI Foundation V2

This update redesigns the public website and creates the shared interface foundation for the rider, driver, and administration experiences.

## Included

- Responsive public header and footer.
- New home page hero, trust strip, services, benefits, FAQ, and CTA.
- Four-step booking wizard with validation, quote review, and success state.
- Redesigned sign-in page with password visibility and demo account shortcuts.
- Responsive authenticated application shell with active navigation and mobile drawer.
- Shared icon set, toast provider, and reusable confirmation dialog.
- Updated design tokens, inputs, buttons, cards, dashboard surfaces, and responsive rules.

## Not changed

- No database schema changes.
- No API endpoint changes.
- No migration or Prisma generation is required.
- Existing booking, dispatch, service-run, and realtime behavior remains unchanged.
