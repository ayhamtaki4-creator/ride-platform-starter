# نشر لوحة إدارة مساعد طريق الشام — مخطط إصدار آمن

**الحالة:** التغييرات في Pull Request #82. إعدادات المساعد وإحصائياته تعتمد على جدولين جديدين في Neon، لذلك **لا تدمج الفرع في main قبل تجهيز قاعدة البيانات**.

## 1) المكونات

- `/admin/assistant`: صفحة إدارة لمستخدمي SUPER_ADMIN وADMIN (التعديل)، OPERATIONS_MANAGER (قراءة).
- `GET /api/assistant/config`: إعدادات عامة للواجهة وCloudflare AI؛ لا تعيد بيانات خاصة.
- `PATCH /api/admin/assistant/config`: حفظ مع الصلاحيات وسجل تدقيق فقط.
- `GET /api/admin/assistant/metrics`: إحصاء تجميعي لآخر 30 يومًا.
- `POST /api/assistant/metric`: يرسل فقط `event` و`topic` من قوائم محدودة، دون نص أو معرف مستخدم؛ يُرسل من العميل **بعد الموافقة على تحليلات الموقع فقط**.

## 2) قبل النشر على الإنتاج

1. تأكد أن النسخة الأحدث تعمل وأن لديك اتصالاً صحيحاً بقاعدة البيانات التي يستخدمها Render.
2. خذ نسخة احتياطية/لقطة Neon مستقلة واستخرج بيانات الاستعادة للتأكد من إمكانية الرجوع.
3. في قاعدة اختبار منفصلة طبّق الترحيل الجديد `20261015030000_assistant_console` وتأكد أن العمليات الأخرى لا تتأثر.
4. على قاعدة الإنتاج شغّل `pnpm --filter api prisma:deploy` من بيئة آمنة بها `DIRECT_URL` و`DATABASE_URL` الصحيحان. هذا **فقط بعد** النسخة الاحتياطية.
5. تحقق من وجود الجدولين `AssistantConfiguration` و`AssistantMetric` ضمن Neon، وبقاء جدول `Trip` و`User` بلا تعديل.

هذا الإصدار **لا يتطلب مسح بيانات أو reset أو seed أو تعديل جدول حجوزات**. ممنوع تنفيذ `prisma migrate reset` أو `prisma db push --force-reset`.

## 3) ترتيب النشر

1. بعد نجاح الترحيل، دمج Pull Request #82 في `main`.
2. دع Render ينشر API. تحقق من `GET https://ride-platform-starter.onrender.com/api/assistant/config` (200).
3. افحص أن `GET /api/admin/assistant/config` بلا توكن يعيد 401، وأن التعديل متاح لمدير المنصة فقط.
4. انشر آخر إصدار `main` على Cloudflare من نفس سير العمل الحالي؛ لا تغيّر الدومين أو إعدادات Cloudflare AI.
5. افتح `/admin/assistant` وجرّب رسالة الترحيب، إضافة سؤال وحفظه، ثم اختبر أن السؤال يظهر في الواجهة العامة.
6. جرّب إيقاف المساعد ثم إعادة تشغيله؛ لاحظ أن الواجهة تحدّث الإعدادات كل 45 ثانية، وأن AI لا يستجيب عند التعطيل.
7. راجع إحصائيات الفترة بعد موافقة متصفح اختبار على التحليلات. لا تظهر أسماء ولا هواتف ولا محادثات.

## 4) ملاحظات مهمة

- إن كان Render في حالة sleep ولم يمكن استرجاع إعدادات المساعد، تُخفى النافذة مؤقتاً (fail closed). تُعاد محاولة التحميل كل 45 ثانية. هذه مقايضة لضمان احترام زر التعطيل، وليست فشلاً في عملية الحجز.
- الإحصائيات **أحداث** وليس عدد مستخدمين فريدين أو محادثات كاملة، وقد تنقص إذا رفض الزائر التحليلات.
- أي تغيير في الأسعار يجري حصراً من لوحة أسعار الحجز، وليس من FAQs. لا تكتب أسعاراً قديمة ضمن الأجوبة اليدوية.
