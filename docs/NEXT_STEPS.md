# خارطة التطوير التالية

## المنجز

- مصادقة JWT وRBAC وحماية الصفحات.
- دورة رحلة آمنة مع PIN مشفر وسجل حالات وAudit Log.
- خرائط OpenStreetMap لاختيار الانطلاق والوجهة.
- مركز عمليات مركزي لتعيين السائق.
- إلغاء التعيين وإعادة التعيين قبل بدء الرحلة.
- WebSocket مصادق للوصول الفوري إلى الإدارة والسائق والراكب.
- Redis Adapter لتوزيع أحداث Socket.IO.
- Polling احتياطي عند انقطاع الاتصال المباشر.

## المرحلة التالية: المسار والموقع المباشر

- خدمة Routing لمسار شوارع فعلي.
- Geocoding وAutocomplete للعناوين.
- إرسال موقع السائق من الهاتف.
- تخزين آخر موقع في Redis.
- إظهار السائق على خريطة الإدارة والراكب.
- حساب ETA والمسافة إلى الراكب.
- PostGIS للبحث الجغرافي والتقارير.

## مرحلة الحسابات والأمان

- Refresh Tokens وجلسات الأجهزة.
- Cookies من نوع `HttpOnly + Secure + SameSite`.
- Rate Limiting لمحاولات الدخول وPIN.
- OTP للهاتف و2FA للإدارة.
- اعتماد السائق والمركبة والوثائق.
- إلغاء الجلسات عند تعليق الحساب.

## مرحلة التشغيل التجاري

- محرك تسعير حسب المدينة ونوع المركبة.
- الدفع والمحفظة والعمولة ومستحقات السائق.
- Push Notifications وSMS والبريد.
- التقييمات والشكاوى والدعم.
- التقارير والتحليلات.
- CI/CD وStaging والنشر الإنتاجي.
