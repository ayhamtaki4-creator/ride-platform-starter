# خارطة التطوير التالية

## المنجز في Milestone 1

- مصادقة JWT وتوجيه حسب الدور.
- إعادة قراءة حالة المستخدم وصلاحياته من قاعدة البيانات.
- حماية صفحات الراكب والسائق والإدارة.
- حساب السعر داخل الخادم.
- دورة رحلة كاملة من الطلب إلى الإنهاء.
- حالة السائق `OFFLINE / ONLINE / ON_TRIP`.
- إخفاء Hash رمز PIN عن جميع استجابات الرحلة.
- سجل حالات الرحلة وAudit Log.
- لوحة إدارة مرتبطة بالبيانات الحقيقية.

## Milestone 2: الخرائط والتحديث الفوري

- دمج Mapbox أو Google Maps.
- Geocoding وAutocomplete.
- حساب المسار والمدة من مزود الخرائط بدل التقدير المبسط.
- تخزين مواقع السائقين عبر PostGIS.
- البحث عن السائقين ضمن نصف قطر جغرافي.
- WebSocket لتحديث الرحلة والموقع فورًا.
- Redis لحالة السائقين المتصلين وتوزيع أحداث WebSocket.
- استبدال Polling الحالي بالتحديث الفوري.

## Milestone 3: الجلسات والأمان

- Refresh Tokens.
- جلسات وأجهزة المستخدم.
- Cookies من نوع `HttpOnly + Secure + SameSite`.
- Rate Limiting لمحاولات تسجيل الدخول وPIN.
- OTP للهاتف.
- 2FA للإدارة.
- إلغاء الجلسات عند تعليق الحساب.

## Milestone 4: التشغيل التجاري

- رفع ومراجعة مستندات السائق.
- محرك تسعير مرن حسب المدينة ونوع المركبة.
- المدفوعات والمحفظة وأرباح السائق.
- الإشعارات Push وSMS والبريد.
- الدعم والشكاوى.
- التقارير والتحليلات.
